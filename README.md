# 📸 gitpo - Gallery Upload

Website sederhana untuk upload dan menampilkan foto-foto. Data disimpan di LocalStorage browser.

## Fitur
- ✅ Upload foto (klik atau drag & drop)
- ✅ Preview sebelum upload
- ✅ Simpan ke galeri
- ✅ Hapus foto dari galeri
- ✅ Responsive design

## Teknologi
- HTML
- CSS
- JavaScript (Vanilla)
- LocalStorage

## Demo
[https://perbasijambi.github.io/gitpo/](https://perbasijambi.github.io/gitpo/)

## Cara Menggunakan
1. Klik atau drag & drop foto ke kotak upload
2. Preview akan muncul
3. Klik "Simpan ke Galeri" atau tekan Enter
4. Foto akan muncul di galeri
